# Мой пет-проект

Идея: Telegram-бот для учёта расходов — записывает трату по сообщению вида
"500 продукты" и присылает недельную/месячную статистику по категориям.

Стек: Python, aiogram, SQLite

Цель: научиться проектировать простую БД под реальную задачу и практиковаться
в асинхронной работе с Telegram Bot API.
